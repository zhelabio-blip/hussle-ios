# Supabase Setup

The authoritative backend files are in `Supabase/`.

Start with:
- `Supabase/README_FIRST_RU.md`
- `Supabase/BEGINNER_SETUP.md`
- `Supabase/MIGRATION_AUDIT_AND_SETUP.md`

For the iOS client, copy `Configs/Secrets.xcconfig.example` to `Configs/Secrets.xcconfig` and add only the public project URL and publishable key. Never place a service-role key in the client or Git repository.
