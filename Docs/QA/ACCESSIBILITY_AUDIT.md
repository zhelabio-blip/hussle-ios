# Hussle accessibility audit baseline

## Implemented in v0.11

- System typography and Dynamic Type-compatible text styles.
- Explicit identifiers for core UI smoke tests.
- Offline and error banners with semantic labels.
- Text labels accompany health and purpose states; meaning is not color-only.
- Primary actions preserve practical 44 pt or larger touch areas.
- Reduced information density on Discover.

## Required before App Store submission

- Run Xcode Accessibility Inspector across every primary flow.
- Add meaningful labels to every dog photo and icon-only action.
- Confirm swipe actions have equivalent buttons and VoiceOver actions.
- Check all screens at the largest accessibility text size.
- Verify contrast ratios for purple text, pink actions and disabled states.
- Respect Reduce Motion on match celebration and card transitions.
- Verify focus order in photo upload, vaccination editor and chat composer.
