# Project Charter

## Product
Hussle is a lightweight iPhone app for dog owners. Its primary discovery goal is finding nearby same-breed dogs for breeding; secondary goals include friendship and walks.

## Product principles
- English-language, App Store-ready experience.
- Minimal, friendly, visually clear UI.
- Same-breed compatibility has the highest discovery priority.
- User safety, privacy, and explicit consent are release requirements.
- Demo Mode must remain functional throughout development.

## Current phase
Candidate prototype moving into Git-based professional development and iterative backend integration.
