# Design System

This file is the permanent source of truth for Hussle visual rules.

## Current direction
- Light minimalist interface.
- Generous white space.
- Soft purple-pink accent family.
- Large dog photography.
- Clear hierarchy and minimal explanatory text.
- Large, obvious Pass and Like actions.

## Demo card information hierarchy
- Keep the dog image dominant.
- Keep the owner portrait visible on Discover as a compact secondary circle.
- Show activity as one short pill, such as `Active today` or `Available this weekend`.
- Show only one concise recommendation reason, such as `Same breed · Shared goal: Breeding`.
- Preserve the existing `Top match` badge when applicable.
- Do not add explanatory paragraphs to the card.

## Match presentation
- Keep Match visually dog-to-dog.
- Show the same concise recommendation reason used on Discover.
- Do not replace either dog portrait with an owner portrait.

## Maintenance rule
Any new reusable color, typography, spacing, component, or interaction rule must be documented here when it becomes approved.
