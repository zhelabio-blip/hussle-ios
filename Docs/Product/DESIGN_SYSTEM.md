# Design System

This file is the permanent source of truth for Hussle visual rules.

## Current direction
- Light minimalist interface.
- Generous white space.
- Soft purple-pink accent family.
- Large dog photography.
- Clear hierarchy and minimal explanatory text.
- Large, obvious Pass and Like actions.

## Maintenance rule
Any new reusable color, typography, spacing, component, or interaction rule must be documented here when it becomes approved.
