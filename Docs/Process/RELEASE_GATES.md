# Release Gates

A candidate must pass all applicable gates:

- Product contract compatibility
- Architecture integrity
- Navigation and state integrity
- Data and backend compatibility
- Demo Mode integrity
- UI consistency and spacing
- Accessibility review
- Error and empty states
- Secret and configuration safety
- Automated/static checks
- Actual Xcode build and runtime check
- Changelog and known-issues update

A failed gate blocks approval unless the exception is explicitly documented.
