# Project Constitution

1. One active implementation task at a time.
2. The Last Approved Build is immutable.
3. Candidate builds may not silently remove approved functionality.
4. Static checks and actual Xcode compilation are reported separately.
5. No build is called compile-verified without a successful Xcode build on macOS.
6. Every completed task requires impact analysis and regression review.
7. New custom components and styles must have concrete definitions before packaging.
8. Quality and architectural integrity take priority over speed.
