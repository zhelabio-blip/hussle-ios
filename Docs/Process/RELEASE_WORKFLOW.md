# Release Workflow

1. Define one task and acceptance criteria.
2. Identify affected product contracts, files, navigation, data, and integrations.
3. Implement in a Candidate Build.
4. Run static repository checks.
5. Run regression and visual QA.
6. Build and run in Xcode on macOS.
7. Record known issues and release evidence.
8. Approve or reject the candidate explicitly.
9. Only an approved candidate may become the new Last Approved Build.
